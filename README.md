# 🧠 Simulación Cerebral con The Virtual Brain

Proyecto desarrollado en Python utilizando **The Virtual Brain (TVB)** y **Streamlit**.

El objetivo es realizar una simulación básica de actividad cerebral en reposo utilizando una conectividad estructural estándar de TVB y desarrollar una interfaz web para visualizar los resultados.

## Características

- Carga de una conectividad cerebral estándar de TVB.
- Matriz de conectividad de 76 × 76.
- Simulación de 76 regiones cerebrales.
- Simulación de 1000 ms.
- Almacenamiento de resultados con NumPy.
- Visualización de actividad cerebral.
- Interfaz desarrollada con Streamlit.
- Layout de dos columnas para gráficos.

## Tecnologías utilizadas

- Python
- The Virtual Brain (TVB)
- NumPy
- Matplotlib
- Streamlit
